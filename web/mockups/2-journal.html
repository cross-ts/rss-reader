Rust 1.88 Arrives With Let-Chains, Ending a Seven-Year Papercut

The release folds one of the language's most-requested ergonomics into the 2024 edition, alongside naked functions and cargo improvements.
By rust-lang.org · 10:02 · 4 min read · unread

The Rust team is happy to announce a new version of Rust, 1.88.0. Rust is a programming language empowering everyone to build reliable and efficient software.

This release brings let-chains to the 2024 edition, naked functions, and a number of quality-of-life improvements to cargo. Let-chains allow you to combine multiple let bindings and boolean conditions in a single if expression, removing a long-standing papercut for pattern-heavy code.

As always, the release also includes stabilized APIs and performance improvements across the compiler.
