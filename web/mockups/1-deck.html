Announcing Rust 1.88.0

2026-07-14 10:02 · rust-lang.org · 4 min · ★ star (s) · ✓ read (m)

The Rust team is happy to announce a new version of Rust, 1.88.0. Rust is a programming language empowering everyone to build reliable and efficient software.

$ rustup update stable

This release brings let-chains to the 2024 edition, naked functions, and quality-of-life improvements to cargo. Let-chains allow combining multiple let bindings and boolean conditions in a single if expression.
