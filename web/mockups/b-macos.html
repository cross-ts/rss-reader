Announcing Rust 1.88.0

rust-lang.org — July 14, 2026 at 10:02 — 4 min read

The Rust team is happy to announce a new version of Rust, 1.88.0. Rust is a programming language empowering everyone to build reliable and efficient software.

If you have a previous version of Rust installed via rustup, you can get 1.88.0 with rustup update stable.

This release brings let-chains to the 2024 edition, naked functions, and a number of quality-of-life improvements to cargo. Let-chains allow you to combine multiple let bindings and boolean conditions in a single if expression, removing a long-standing papercut.

As always, this release also includes stabilized APIs, performance improvements across the compiler, and updated tooling. See the detailed release notes for the full list of changes.
